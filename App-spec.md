# Eternal D Collab

A simple free AI collaboration app.

## Goal

Free real-time chat and tasks.
## First version

- Create a shared workspace and invite someone to join.
- Send and receive messages in a shared chat. New messages appear without refreshing.
- Create tasks, assign them to workspace members, and mark them complete.
- Ask the AI to suggest tasks from a chat discussion. Review the suggestions before adding them to the task list.

## First test

Two people join the same workspace. One sends a message, and the other sees it without refreshing. They ask the AI to suggest a task, add it after reviewing it, and confirm that both people see when it is marked complete.

## Technical Setup

### Application Structure
- Frontend: Web-based chat interface
- Backend: Server for AI and collaboration
- Database: User accounts, messages, and workspaces
- AI Integration: Connect to an AI model using a secure API

### User Accounts
- Users can create accounts.
- Users can securely log in.
- Each user has a personal profile.
- Users can create or join shared workspaces.

### AI Assistant
- Responds to user messages.
- Helps users complete tasks.
- Supports conversations within shared workspaces.
- Can be expanded with new capabilities.

### Security
- Protect user information.
- Keep API keys on the server.
- Restrict workspace access to authorized users.
- Store information securely.
